# Example data

`S170_1cm.ply`: room S170 from the test area of the 3DSES dataset, thinned to 1 cm voxels (918 476 points, binary PLY, x y z as float in metres, colour).

Source: Mérizette, M., Audebert, N., Kervella, P., Verdun, J. (2024). *3DSES: an indoor Lidar point cloud segmentation dataset with real and pseudo-labels from a 3D model.* Zenodo. [doi:10.5281/zenodo.13323342](https://doi.org/10.5281/zenodo.13323342)
